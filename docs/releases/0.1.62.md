
- 🚑 **0.1.61 would not start from the Windows installer.** The backups module added in 0.1.61 is CommonJS and the packaged backend is an ES module package, so Node read it as ESM, the API died on its first `require` and the desktop stayed on the "Starting HydraOps…" page. The module is now a `.cjs` file, which Node loads as CommonJS wherever it sits. Nothing else changes: install this version over 0.1.61 and the app starts with the backups feature intact.
