- 🖼️ **ComfyUI results in their card.** An image, video or 3D model a connection's tool names in its answer (ComfyUI's fetch_outputs, for instance) is brought into the task and shows in its card under the reply, like a generated image. It is taken straight from your ComfyUI under the name it saved it with, whatever the model; a temporary copy is used only as a fallback, and only from where tools leave their output.
- 🧰 **Tools on demand, leaner.** A connection with more than 15 tools is no longer loaded whole: the model gets its list and names the ones it needs. A loaded tool left unused for 3 steps is unloaded, and the previous task's tools are preloaded only when your message does not name another connection. Measured: about 7,000 input tokens per tool call, down from about 36,000.
- 🎨 **Tools by color in the agent's profile.** Add-ons, built-in tools and MCP servers each have their color, with a legend.
