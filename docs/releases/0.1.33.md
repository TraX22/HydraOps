- ⏹️ **Stop a task.** A **Stop** button sits next to the "typing" dots, and `/cancel` does the same from the chat box or from Telegram. The task turns *Cancelled* at once and the worker really aborts the model call: a cloud model stops generating and billing, your local model frees the GPU. Tasks still waiting in the queue can be cancelled too.
- 🎨 **Image, video and 3D can be stopped as well.** Image and video agents stop waiting for the render and discard the result, and the 3D plugin has a **Cancel** button on its working badge — handy with reasoning models that take minutes.
- 🔎 **Answers keep their sources.** When an agent searches the web or opens pages, **Sources · N** appears under its reply: ● pages it opened, ○ pages that came up in a search. The same addresses stay in the conversation, so a later "give me the link" returns the real one.
- 🤝 **No more made-up links.** Agents now follow a rule: only give a URL they actually opened or saw, never rebuild one from memory, and never call it "verified" unless they opened it in that same turn.
- 🔗 Links in replies are blue, in both themes. Cancelled tasks no longer count against an agent's success rate in Stats.
