- 🧰 **Tools on demand.** When an agent has more than 12 tools, the model no longer gets every definition on every call (tens of thousands of tokens, even to answer one line): it gets an index, name and one line per tool by connection, and loads the full definition only of the ones it is going to use. Tools you name in the message and the ones the chat used in its previous task start loaded. Measured on a request for a prompt: 19,464 input tokens down to 4,267. A switch in Settings turns it off.
- ✅✅ **Approve for the rest of the task.** A held call's card, and its Telegram notice, offer a third choice: the call runs and the same tool no longer asks in that task and its continuations. Tools that always ask keep asking.
- 🔁 **Approval chains that never go silent.** A task can resume up to 20 times after your decisions (it was 5), and if it ever reaches that limit the chat gets a note with what ran and how to go on, instead of nothing.
- 🧩 **ComfyUI: your saved workflows first.** The agent is told to list the workflows saved in your ComfyUI before the online templates (held for approval, with models you may lack), and to bring a finished job's files into the chat itself instead of leaving them in a temporary folder.
