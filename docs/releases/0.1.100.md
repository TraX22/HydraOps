- 🪶 **Lighter prompts for agents that can create skills.** An agent with `create_skill` carried the whole skill-writing guide in its instructions, on every step of every task: about 7,000 characters, half the prompt of a simple agent. The guide now stays out until it is needed: when an agent is about to write a skill it asks `create_skill` for it, with a call that proposes nothing and needs no approval. A proposal still waits for you, exactly as before.
- ✉️ **Gmail: a new message is read in one step less.** A task started by a new e-mail already says which account and which message, but some models first listed their accounts and only then read the message: a third more cost on every notice. The task now says the account is the agent's own, and to go straight to the message.
