
- 🖼️ **A picture a tool returns is a card in the chat.** When a connection's tool answers with an image (Unity's scene and game captures, Blender's viewport capture, a browser screenshot), the picture was kept for the model only, and a card appeared under the reply just when the tool had also saved a file in a folder the connection is configured with. Now the inline picture itself is written with the task and shown as a card, so "show me a capture" needs no save path and nothing in the application's own folders; when the tool did save a file within reach, that file is the one card.
- 📁 **A relative path in a tool's answer is found under the connection's folders.** Unity's capture tools answer with a path relative to the project (`Assets/Screenshots/view.png`) and the chat got no card for it, since only absolute paths were recognised. Such a path is now looked for under the folders the connection is configured with (the project given to `--project-path`, for instance), only there, and never outside them.
