- 🗞️ **Scheduled tasks no longer deliver the same news again.** A task like "read this feed and bring me what is new" kept a memory of only its last three answers, so two "nothing new" days in a row made it forget the list and send it again. Each task now keeps a record of the links it delivered and of what each page it read said, and the app itself removes what was already delivered: an unchanged feed gives one line, a changed page is kept. Ask for the link of each item in the task; an item without one cannot be told apart from a new one.
- 📭 **A scheduled task has to open its sources.** If a task names its feeds or pages and the agent answers without opening any of them, it is asked once more; if it still does not open them, you get a notice instead of a digest that could be made up.
- 🧠 **Agents remember the last 30 days of a chat.** An agent used to see only the last 24 hours, so "the sites you suggested yesterday" drew a blank. It now gets the last 20 exchanges of the last 30 days (less with a local model, so its context does not fill up), older messages carry their date, and the chat shows the same 30 days.
- 📋 **Text meant to be copied comes in a frame with a copy button.** Prompts, commands and messages to send now arrive in their own block, separate from the agent's comments, and long text in the frame wraps instead of scrolling sideways. Telegram shows it as one block too.
- 🖱️ **Selecting text in the chat works again.** A selection in an agent's reply was wiped a second later, because the reply was redrawn on every refresh of the history.
- 🔒 Build tooling updated for a critical advisory in `piscina` (used only while compiling the interface; it does not ship in the app).
