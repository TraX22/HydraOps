- 🧩 **Skills for your agents.** Skills are step-by-step know-how, like how to research in depth, write for X or YouTube, audit a page's SEO, or write so it reads human. Install them from the official catalog in **Tools → Skills**, or copy one into the skills folder by hand. An agent uses them only if you give it the `skills` tool; it sees just the names and opens a skill when a request needs it.
- ✅ **Agents can propose their own skills, and you decide.** An agent with `create_skill` can write a new skill after working something out. It is never saved on its own: it waits for your Approve / Reject in the chat, in the Skills panel or on Telegram, and it stays on your computer.
- 🔍 **A safety check before installing.** **View** shows every file of a skill and flags phrases that try to take over the agent, credential file names, "download and run" commands and hidden text. Downloads are checked against the catalog so a tampered file is not installed.
- 🔗 **Links show where they really go.** Hover a link in a reply to see its real address. A link whose text names one site but points to another gets an orange ⚠, and a link the agent didn't actually open or see in this conversation gets a small "?".
- 📐 **Replies look like documents.** Tables got rounded corners and a soft accent colour that works in both themes, and lists, headings and quotes in agent replies have their proper shape again.
