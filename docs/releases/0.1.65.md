
- 💾 **Backups live outside the data folder.** A copy of the installation was kept under `backups/` inside the data folder; running from source that folder is the clone itself, so deleting the clone to "reinstall" took the agents, the chats and every copy with it. Copies now go to your own configuration folder (`%APPDATA%\HydraOps\backups` on Windows, `~/.config/HydraOps/backups` on Linux, `~/Library/Application Support/HydraOps/backups` on macOS), one subfolder per installation, and `HYDRA_BACKUPS_DIR` moves them elsewhere. Copies made before this stay where they are, listed, restorable and deletable, marked *in the data folder*.
- 📂 **System says where your data is.** The System view now shows the data folder (agents, chats, settings) at the top and, running from source, that it is the clone itself: update it with `git pull`, never delete it to reinstall, make a copy before touching it. The installation manual says the same.
- 🧠 **Current Claude models as the fallback.** When Anthropic's model list cannot be fetched, the choices offered are Sonnet 5.5, Haiku 5.5 and Opus 5.5 instead of one older model.
