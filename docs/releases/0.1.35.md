- ⏸ **Actions wait for your OK after an agent reads outside content.** If an agent opened a page, a search or a third-party file and then wants to send a message, write to GitHub, save to its permanent memory, generate a video or use an MCP tool that acts, the call is not run. A card appears under its reply with the tool, the exact arguments and where the content came from: **Approve** runs that stored call as-is, without the model; **Reject** discards it. Undecided calls expire after 24 hours, and Telegram tells you when some are waiting.
- 🛡️ **You choose how strict.** Each agent's profile has an *Outside content* setting (ask for approval, the default, or trusted), and Config has a global switch (ask / trust / off). Images are not held — they are already limited to one per task.
- 📊 **Diagrams in colour.** Mermaid diagrams from your agents now use HydraOps' own palette in both themes, take the full width of the chat, and open full screen with a click (Esc closes).
- 📘 **Updating from source, documented.** The manual now explains how to update a Linux, macOS or from-source install — the in-app Update button or `git pull` + `pnpm serve` — and what to do if `git pull` reports divergent branches on an older clone.
