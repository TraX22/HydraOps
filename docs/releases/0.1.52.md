- 🧩 **ComfyUI workflows, ready to run.** A new tool, `comfy_workflows`, lets an agent use the workflows you saved in your own ComfyUI: it lists them, prepares one (a copy, with the files you attached uploaded and placed in its inputs) and brings back what the finished job saved, under a recognizable name and with its real size. It works next to a ComfyUI connection, through ComfyUI's address; your saved workflows are never changed.
- ⏱️ **Connections whose tools take minutes.** A tool call of a connection was always cut at 30 seconds. A connection can now be given more (`toolTimeoutSeconds`, up to an hour) for tools that wait on a render or a generation; catalog connections that need it carry their value.
- 🖼️ **The agent knows the file behind an attached image.** The model was shown the picture but not the name it is stored under, so a tool that needed the file was given an invented name. The stored name now travels with the image.
- 💸 **Claude models cost much less in long tasks.** Prompt caching is now asked for with Claude models, through Anthropic's API or OpenRouter: each tool round used to pay the whole conversation again at the full input price.
- 🧾 **A failed or cancelled task shows what it used.** The tokens of the rounds that finished before the failure were billed but stored as zero; they are now recorded and counted in Stats.
