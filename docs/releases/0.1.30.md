- 🧊 **New plugin: 3D (beta)** — describe an object and the model *writes the Three.js code* that builds it; an isolated canvas renders it on the spot. Orbit it, iterate ("make the stripes blue and add a boat"), and **export `.glb`** straight into Unity. Works with any text model, including your **local** one, and ships Three.js inside the app — no internet needed.
- 🛠️ **Built to look right on the first try** — the model gets a helper kit (lathe profiles, extruded outlines, mirror, ring/grid repetition, shared materials), a design method and a worked example; runtime errors are sent back to the model and fixed automatically (up to twice). Studio-style lighting makes metals shine instead of rendering black.
- 🖼️ **Reference image** for vision models, saved scenes with thumbnails, a Code tab to read or hand-edit the result, and a live "working" badge with elapsed time for slow reasoning models.
- ⌨️ **New commands**: `/3d`, `/plugins` and `/open <view>` (jump to docs, config, stats, tasks…). `/engine` now shows the engine by name, and the docs list every alias.
- 🔒 Generated code runs in an opaque-origin sandbox: it cannot reach the app, your data or your keys.
