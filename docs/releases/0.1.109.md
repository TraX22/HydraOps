- 💸 **Loading a tool half-way through a task no longer makes Claude read everything again.** An agent with many tools loads the ones it needs as it goes. Each load changed the start of the request, so the next step paid the whole conversation at the full price instead of reading it from the cache. On Anthropic's current models (Opus 4.8 and later, Sonnet 5.5, Haiku 5.5) the tool list now stays as the task first sent it, and a tool loaded later travels inside the conversation. Measured with a real agent on Haiku 5.5: the step after a load went from 0% to 89% read from the cache. If the provider refuses the request, it is sent again the old way and the task carries on.
