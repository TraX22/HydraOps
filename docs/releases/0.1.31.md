- ✨ **What's new, inside the app.** After every update a closable **What's new** tab appears in the chat with what the release brings — and if you skipped versions, it lists the ones you missed. The notes ship with the app, so they work offline. Type `/whatsnew` to read them again at any time.
- 🧊 **3D: "Improve prompt".** One click turns a short idea ("a treasure chest") into a build brief with size, main shapes, details and palette, in your language. Read it, tweak it, then generate; **Undo** brings your original text back. Helps mid-size and local models the most.
- 🎨 **3D: style presets** — Free, Low-poly, Voxel, Game prop, Realistic. The style shapes both the brief and the code, is saved with the scene and remembered between sessions.
- 🛟 **3D: no more silently blank canvas.** Helper calls with the wrong arguments now fail with a clear message that goes back to the model for an automatic fix, NaN geometry is caught instead of reported as "ok", and `roundedBox` takes the same argument order as `box`.
- 📦 Export notes now cover **Unity, Unreal and Blender**: how each one imports a `.glb` (Unity needs the official glTFast package).
