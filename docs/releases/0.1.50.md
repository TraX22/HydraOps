- 📎 **Drop files on the chat, or paste an image.** Dragging files over the chat shows where to drop them, and dropping attaches them like the paperclip does. Ctrl+V in the message box attaches a copied image, a screenshot for instance.
- 🔗 **Leaving the app asks first.** A click on a link to another site opens a small balloon with the full address, the site in bold, and Cancel / Accept. Links the agent did not open or see are now marked with a yellow warning triangle instead of a question mark.
- 🪜 **Steps per task, per agent.** Each agent's profile has a new setting: 15 (the default), 30 or 45 tool rounds per task. An agent that builds long things can get more without raising the cost of every other agent.
- ⚠️ **No more false "executed successfully".** When a task used up its steps and the final answer could not be written (the provider out of credit, a rate limit), it ended with a success mark and no report. It now says what happened and why, and that the work the tools did is real.
- 🔎 **A blocked web search says so.** When DuckDuckGo refuses a search, `web_search` used to answer "No results found" and the agent concluded the thing did not exist. It is now told the search was blocked and nothing was searched.
- 💸 **A little less per step.** Tool images leave the conversation in blocks, so the provider's prompt cache is not thrown away on every capture, and a skill opened twice in a task is sent once.
