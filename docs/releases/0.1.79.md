- 📅 **A shared calendar.** Every agent now reads a calendar and, with your approval, writes to it. A **note** (a meeting, a delivery, "no GPU until the 20th") is context: each task starts with the agenda of today and the next 7 days in front of it, and a note with a time reminds you on Telegram. An **action** is a task set for later: "Thomas, publish this thread on Friday at 10" — at that time the agent gets it as a new task in its chat, with the files the action reserved (copied when you approved it, so they survive the task vault's cleanup). Repeats daily, weekly, monthly or yearly; the time zone is stored with each entry (yours by default); an action that came due while HydraOps was off still runs within 6 hours, later it is marked missed and you are told. Give an agent the tools with `- calendar` in its tools.md; the Calendar view in Complementos comes next. See the "The calendar" section in Scheduled tasks.
- 🔒 **Outside content stays outside.** A calendar entry written by a task that had read a web page or a feed keeps that origin: it is left out of the agenda the agents get, reaches them only marked as external data, and a task it starts is treated as tainted, the way a delegated task is.
