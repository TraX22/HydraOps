- 🖥️ **HydraOps lives in the system tray.** Closing the window no longer stops anything: agents, scheduled tasks and the Telegram bot keep running while the icon sits next to the clock. Click it (or launch the app again) to bring the window back; **Quit** in its menu is the only thing that stops the stack. New in Config → Desktop: **Start with Windows** and **Start in the tray**, for a machine that runs 24/7. Every shutdown is written to `shell.log` with its reason.
- 🧭 **The main chat picks the right agent.** Messages without an @mention used to be dealt out in turns. Now a fast model reads the message and each agent's role and routes it: C# questions reach the coder, game assets reach the illustrator, AI news reach the researcher. Falls back to the old rotation if the model does not answer; `ROUTER_MODEL` picks a cheaper model for it.
