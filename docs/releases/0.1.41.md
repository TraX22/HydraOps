- 🗄️ **The task vault: long pages are no longer cut.** Until now each tool trimmed its result (a web page at 4,000 characters, a transcript at 15,000) and whatever fell off was gone, so a question about something deep in a page could not be answered. Now every long result is kept whole for the task and the agent gets the beginning, an index of the document's sections and a `[vault #n]` marker; with `vault_read` it opens a section or keeps reading, with `vault_find` it searches what it stored. The working row shows **vault: N** with the documents kept so far, and "show steps" names each read-back ("Reading back from the vault #1 · Reception"). Vaults are removed after 24 hours.
- 💬 **The chat stays where you left it.** The history poll no longer moves the view every couple of seconds: it only scrolls when a new message arrives or a reply finishes, so you can read the links, sources and model line under a long answer without being pulled back to its start.
- 👤 **The typing bubble has a name from the first moment.** In an agent's chat it is born with the agent's name and avatar instead of reading "Agent" for a second and then changing.
