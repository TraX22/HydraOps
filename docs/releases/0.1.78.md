- ✏️ **Editing a message sends it again.** Hover one of your messages, press the pencil, change the text and save (Ctrl+Enter; Esc cancels): the message goes out again as if you had just typed it, the old exchange with its reply leaves the chat, and the agent answers the new text. A task still waiting in the queue is just rewritten. Before, saving only changed the stored text and nothing happened. The edit box is now as wide as a message and as tall as the text.
- 🖼️ **`image_edit`: plain image edits without a GPU or Blender.** A new native tool measures an image of the task (size and the subject's box), crops, flips, rotates, resizes, trims the plain background away, or composes several images on one canvas (a sheet of views from single pictures, a mirrored profile next to the original, with `equal_heights` so the figures match). The result is saved in the task's folder, shows up in the chat and the agent is shown it to check. Nothing outside the task is touched, so it runs without approval. Add `image_edit` to an agent's tools to give it.
- 🔌 **The real answer from a model's service, not "fetch failed".** When a service (Anthropic, OpenAI, Hugging Face…) answered before reading the whole request — a 429, a 529 "overloaded", a 400 for an image too large — the key-proxy turned it into a blind "Upstream request failed" and the SDK retried without knowing why. The request body now goes out whole, so the real status reaches the caller and the log says the cause.
- ⏱️ **The 3D plugin stops a model call it gave up on.** The 10-minute wait for a scene (3 for a brief) now aborts the call: before, the plugin reported a timeout while the call went on alone, finished later and was billed. The message names the model and the wait; `THREED_TIMEOUT_MIN` raises it for slow reasoning models.
