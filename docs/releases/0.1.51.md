- 🔀 **OpenRouter models go to OpenRouter.** A model chosen with an OpenRouter id whose name also belongs to a provider with its own key (`google/gemini-…`, `openai/gpt-…`, `anthropic/claude-…`, `mistralai/…`, `x-ai/grok-…`) was sent to that provider's API and failed with "Not Found"; ids with a size in the name (`meta-llama/llama-…-70b`) were sent to the local server. Any `vendor/model` id now uses OpenRouter and its key. Local models and ids without a vendor prefix work as before.
