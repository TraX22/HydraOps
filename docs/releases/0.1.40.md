- 🗺️ **Plan before doing.** Put `/plan` in front of a big, costly or hard-to-undo request and the agent proposes first: it only has the tools that read, so nothing is sent, saved, delegated or generated until you say so. The plan arrives as a card with the goal, the numbered steps and the tools each one uses (orange for the ones that act), the agent a step is delegated to and the questions worth settling first. **Approve and run**, **Edit** the text and approve that version, **Ask for a revision** (the next version lands in the same card with new / changed / removed marks and what the change implies; v1 · v2 · v3 chips jump between them) or **Discard**. While a plan is waiting, what you type is a revision of it. On Telegram it arrives with ▶ Approve / ✕ Discard.
- 🧠 **Long research jobs finish properly.** When an agent hits the limit of tool calls in one task, the final answer is now written from everything it gathered instead of the last round only, and it is told the limit was reached. No more "my searches did not run" after twenty sources were read. The limit is 15 steps (override with `HYDRA_LLM_MAX_STEPS`).
