- 🖱️ **Agents can act in the browser panel, with your approval.** `browser_act` lets an agent click, type into a field (and press Enter if asked), pick an option, submit a form or scroll, on the tab the panel shows. The agent names the element by what you see, a button's text or a field's label, never by code; the panel finds it, scrolls to it and highlights it for a moment before acting with real input, so the page reacts as it would to you. Every action waits for you: the card says what the agent wants to do, on which element and the exact text it will type, and approving opens the panel so you watch it happen. Password, card and file fields are never touched, an ambiguous name is refused with the choices listed, and after a navigation the agent gets the new page's title, address and a short excerpt. Grant it in Agents → tools next to `browser_read` and `browser_open`. Desktop app only.
- ➕ **Adding a tool to an agent is visible now.** The tools editor (Agents → tools.md) ends with an **Add tool** button that opens the list of what can be granted and puts the cursor in the filter; the filter keeps a short placeholder when the agent already has tools, and after picking one the cursor stays there for the next. A click anywhere in the box still works, as before.
