
- 💾 **Backups, from the System view.** A new *Backups* section keeps copies of what makes the installation yours: the agents, the installed skills and add-ons, the users, the settings and the database with every chat, task, schedule and connection. Make one whenever you want (task files and API keys are optional, off by default); one is made on its own before every update, with the five newest automatic copies kept. **Put back** replaces the current data with a copy and restarts the app: tasks in progress are cancelled, the services stop, the files are swapped and everything starts again, on the desktop, under `pnpm serve` and under systemd alike. The state you had right before is kept as a copy too, so a restore can itself be undone. A copy is a plain folder under `backups/` in the data folder, with a manifest: nothing to unpack, easy to copy elsewhere. Documented in Statistics & System and in Troubleshooting.
- 🧩 **ComfyUI: a crop region reaches the server as saved.** The connection's converter (comfy-cli 1.22.0) drops a widget whose value is a record, such as `ImageCropV2`'s crop region, and the node ran with its default: the four crops of a multiview workflow all became the same corner of the picture and the model came out as a symmetric tower. `prepare` now writes such a node's values by name, which the converter honours, and reports it. Twenty-one node types with record widgets (crop regions, video trim and crop, curves, painted masks, bounding boxes) are covered.
- 🖼️ **ComfyUI previews stay out of the chat.** A job's intermediate previews (the mask, the UV atlas, the baked texture maps) were brought in as result cards, eight of them above one model. Only what the workflow saved is shown now, as `collect` already did.
