- 🌿 **The agents can use Git.** Three new tools work with the Git installed on your computer, inside the folders you allow in **Tools → Git** and nowhere else: an agent sees what changed in a project, commits it, makes branches, and pulls, clones and pushes with GitHub. Give them to an agent with the `git` tag; they are apart from the `github` tools, so an agent can have either without the other. Pushes, pulls and clones use the token of the GitHub card, which the agent never sees, and work with Git LFS.
- ✋ **A push always waits for you.** It is the step that leaves your computer, so it is held every time, whatever the task read and whatever the security setting. The card shows the folder, the branch, the GitHub repository and the commits that would be sent. Nothing is ever forced, and history is never rewritten.
- 📖 **Set-up in the manual.** The Tools page explains how to install Git and Git LFS, how to choose the folders, and which permission the GitHub token needs to push (Contents: Read and write).
