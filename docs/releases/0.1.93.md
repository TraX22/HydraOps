- 🔧 **A connection's variables are filled in where they are shown.** A connection from the catalog often needs one value of yours before it is useful: the ComfyUI connection wants `COMFYUI_PATH`, the folder of your ComfyUI install; the Unity connection `UNITY_PROJECT`. Until now **View** in Tools → Connections only listed those variables, and the value had to be written as JSON in Add-ons → MCP servers. Now, once the connection is installed, **View** shows one field per variable with its current value and a **Save** button (Enter saves too); under them, the folder the connection will start in, with a mark saying whether it exists on this computer. Only the values change: the command, its arguments and the tool classification stay as installed, so the connection still updates from the catalog, and the worker that runs it restarts it with the new values within a minute. Add-ons → MCP servers remains the place for anything beyond the values.
