- ✍️ **The agent proposes the commit message.** When you accept a project's changes, the message box holds one line from the agent saying what the change does, in English unless you ask for another language. It used to offer your last chat message, which made for commits titled "done". The tab says the line is the agent's; edit it or write your own.
- 🔁 **The agent knows what you did with its changes.** Accepting, discarding or editing a file by hand in the project's tab is told to the agent at its next turn. It no longer goes on as if a discarded change were still there.
- 🙈 **A project's own files stay out of your commits.** `HydraOps.md` and `ProjectMemory.md` go on the repository's local exclude list, so `git add .` leaves them out and your `.gitignore` is not touched. If one is already in your history, its panel gives the command to stop following it.
- 🔐 **More secrets files are protected, and templates are not blocked.** Every variant of `.env` and `.dev.vars` is off limits to agents, including names like `.env.production.local` that were not covered before. The templates a repository ships (`.env.example`, `.env.sample`, `.env.template`) are ordinary files the agent can read and write.
- 📂 **Show in folder.** In the desktop app, a file open in a project's editor can be shown in your file manager with one click.
- 🗂️ **Cards fold in Add-ons and Tools.** Every card starts folded to its name and one line, so each view reads as a list. An arrow opens the ones that have more.
- ⌨️ **The message box grows with what you write.** A long prompt can be read before sending: the box grows up to two fifths of the window, then scrolls.
- 🙂 **The chat follows the agent while it works.** The "see steps" link is no longer cut off behind the message box, and the agent's bubble keeps its picture instead of turning into a letter until the reply arrives.
- ↔️ **The browser panel's edge is easier to grab.** The dividing line and its mark are twice as thick.
- 🧠 **Several things remembered at once are saved cleanly.** When an agent saves several notes in one step, each lands on its own line, in the agent's memory and in a project's notes, and the memory file's size limit holds.
- 🖥️ **Projects on a server say when a folder is read-only.** Under the systemd unit a project's folder has to be listed in the unit. The tab now says so, and the manual has the steps.
- 🧹 **Start-up logs no longer print the NATS address with credentials.** Only the host and port are written.
