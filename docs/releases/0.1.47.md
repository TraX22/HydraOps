- 👁️ **Agents can see the pictures their tools return.** A viewport capture from Blender or a page screenshot from a browser server used to reach the model as the words "image omitted", so an agent "checked the viewport" without seeing it. Now a model that can see images (OpenAI, Anthropic and Gemini chat models, among others) is shown the picture right after the tool result, and a model that cannot is told plainly that it was not shown, so it does not claim to have looked. With a local model, set `LOCAL_LLM_VISION=1` if your server has the multimodal projector loaded.
- 🧭 **Choose the model that routes the main chat.** Config has a new field, "Main chat routing model": the model that reads each main-chat message and picks the agent. Left empty it uses the default model, as before; with a heavy local default, a fast model here turns a wait of several seconds into about one.
- ⏳ **A connection's first start is no longer cut short.** A server started through `uvx`, `npx` or `docker` has to download itself the first time, which can take a minute; HydraOps gave up after 10 seconds and killed the download with it. Local servers now get three minutes to connect.
- 📚 The README and the manual are caught up with the last releases (Skills, `/plan`, approvals, the task vault, Connections, the 3D plugin), and the Spanish interface says "predeterminado" where it said "por defecto".
