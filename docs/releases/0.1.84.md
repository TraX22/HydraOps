- 🌐 **A browser beside the chat** (desktop app). The globe at the top right of the chat opens a panel with real Chromium tabs, the one bundled with the app: address bar (a bare host opens as https, local addresses as http, anything else searches), back, forward, reload, a button to open the page in your system browser, and a draggable edge. Sessions persist between restarts in the panel's own profile; a page never gets the camera, microphone, your location or notifications; links that want a new window open as a new tab here. The panel remembers whether it was open, its width and its tabs.
- 👁️ **Each tab has an eye** that says whether an agent may read it: the tab you are looking at is readable, the others stay hidden unless you switch them on (and you can hide the active one too). This version records your choice; the tools that let agents read a tab and open pages in the panel come next.
- 🖥️ The panel needs the desktop app: in server mode (the interface in a plain browser) the globe does not appear.
