- 🗄️ **No more approval cards for work that read nothing from outside.** Reading a document back from the task vault used to mark the task as having read third-party content, whatever the document was, and from then on every tool that acts waited for your approval. Now only documents that did come from outside (a web page, a search) mark it: an agent modelling in Blender, with no web reading, runs straight through.
- 📖 **Skills reach the agent whole.** An installed skill longer than 2,500 characters was being handed over as a short digest, so the agent had to go back for the rest of its own instructions. It now gets the full text in one go.
- 🎨 **Image generation with Google works again.** The default engine pointed at an Imagen model that Google has retired, so an agent with its image engine on "automatic" failed every drawing. The Gemini image models (`gemini-3.1-flash-image` and its siblings) are now supported, and one of them is the default.
- 🔒 Angular 21.2.25 and DOMPurify 3.4.16 (two security advisories).
