- 👁️ **Agents look at what they generate.** When a ComfyUI job makes an image, the agent is shown it (a lighter copy; your file stays the original) and checks it against what you asked — the character, the colors, whether several views match — before it reports, instead of saying it has not seen it. Models that cannot see images still say so.
- 🔁 **Feeds that bounced through a sign-in check read again.** Some sites answer only on a second pass and send a reader round a redirect loop first; the Android Developers Blog feed is one. `fetch_url` now keeps the cookies a site sets while it follows those redirects, for that one request only, so the feed comes back instead of "Too many redirects".
