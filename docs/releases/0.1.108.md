- 🧾 **An answer that names a tool it never called says so.** Some models, small local ones above all, write "(running `project_write` on main.c)… done" without calling anything. When an answer names a tool the agent has and the task made no call to it, the chat puts a warning under the answer, Telegram adds the same line, and the agent's next request is told, so it does not build on work that never happened.
- 🚫 **The agent learns that you rejected what it asked for.** When you turned down every call of a task, nothing recorded it: the agent's last word was its own "waiting for your approval", and on your next message it could ask again or carry on as if it had run. It now reads which calls you rejected and that none of them ran. Rejecting still starts nothing and spends no tokens.
- 📅 **A scheduled post tells you in the chat when it goes out.** The outcome used to reach only the Calendar and Telegram. It now arrives at the end of the agent's chat too, as an unread message written by the app: the link of every part of a thread and what it cost. Ask the agent afterwards whether it went out and it answers from that message, without going to X to look.
- 🪶 **Every step of every task sends less.** The list of installed skills in an agent's prompt is one short line per skill instead of up to 300 characters each. With 58 skills installed that is about 8,500 characters less on each step (28% fewer tokens on the first step of a test agent); the right skill was still opened in the same requests. The list holds 120 skills now, up from 60.
- 📥 **A project command that will download software says so before you approve it.** The card of `npm install`, `pip install`, `cargo build`, a `git clone` and the like now warns that it is likely to download and install, in the chat and in Telegram.
- ⏳ **A long answer from a cloud model is no longer cut at five minutes.** The key-proxy waits up to 26 minutes for the provider, and stops the request when whoever asked for it has gone, so an abandoned task does not keep spending.
- 📖 **In the manual.** A troubleshooting note for an agent that says it did something, what happens when you reject every call of a task, and the scheduled post's message in the chat.
