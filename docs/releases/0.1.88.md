- 🗂️ **The files of a conversation stay at hand.** When a reply leaves a file (an image a ComfyUI workflow saved, a model, a crop), the next request can be about it: "now remove its background", "send that model to Blender". The agent sees the files the recent replies of that chat left, with the path the chat shows, and `image_edit`, `comfy_workflows` and the connections on your computer open them by that path, read-only; whatever they produce still lands in the new reply. Before, each task saw only its own attachments and results, and the agent asked for the file again.
- 🪄 **`image_edit` makes a flat background transparent.** A sprite or a logo on a plain color becomes a PNG with alpha in one step and with no GPU: the tool keys out the corner's color, or the one the agent names, with a tolerance; if nothing matches it says so instead of saving a copy.
- 🧩 **ComfyUI: the models a workflow really loads.** A workflow built from an official template often keeps its loaders inside a subgraph whose file choice sits on the subgraph's panel. `comfy_workflows` read the template's inner defaults, so a Klein workflow switched to the bf16 files listed its int8 defaults as missing and an agent would have offered to download 17 GB. It now reads what the panel sets, and says next to it what the template declared, since the download link is for that one.
- 📎 **Attachments reach the connections.** The conversation names an attachment as `storage/uploads/<name>`; a connection's tool (ComfyUI's `upload_file`, for instance) received that relative path, looked it up in its own folder and failed. A connection running on your computer now receives the file's full path; a connection on another machine receives the name as written. `comfy_workflows` also says that "prepare" uploads attachments itself.
- 📅 **Calendar: the month stays in view, and "today" keeps up.** In the left bar only the agenda list scrolls now; the heading and the mini month stay put however many entries are coming. And a calendar left open past midnight moves to the new day on its own: the day and week views showed yesterday ("Nothing that day" with an action due today) until the window was closed and opened again.
- 🧹 **Two small things in the interface.** The Calendar card in Complements is now the same size as One Shot and 3D. And the notes a `/plan` command leaves in the chat (its line and the "Planning…" notice) go away when you delete the plan's message, instead of staying on screen until the next restart.
