- 🧩 **Values set on a ComfyUI workflow reach the server.** `comfy_workflows` has an action `set` that writes values on the prepared copy of a workflow by address (`<node>.<input>`, the addresses `list_workflow_slots` prints): a prompt, a seed, a step count, and also a node's record value such as `ImageCropV2`'s crop region. Setting a crop region through the connection's `set_workflow_slot` left the server running the node's default (the same 512 × 512 corner four times in a multiview template); `set` keeps those values in the form the converter reads. A value fed by another node is refused, naming the link.
- 📐 **Uploaded images come with their size.** `prepare` notes the pixel size of each image it uploads (`uploaded "sheet.png" (1360 × 768 px)`), so an agent can work out crop regions instead of guessing.
- 📦 **Skills with more reference files.** A skill may carry up to 50 files (was 40); some published skills, such as the official Unity ones, ship more than 40 reference files and could not be installed.
- 🐦 **X posts that come back without a link.** When X creates a part of a thread but does not return its id, the part is reported as published without a link (it is under the previous part on X) instead of a broken address or a second attempt; the next part replies to the last post whose id is known.
