On Telegram, deciding in the app takes the buttons off the notice and adds how it went.

- 📊 **Skills on the agent cards.** Statistics cards have a new Skills attribute: hover it to see how many times each agent used skills and which ones.
- 🧊 **3D: every object framed, and a clean view for pictures.** A 20 cm flower pot now fills the view like a house does, and the grid follows its size. The clean view hides the grid and adds a soft backdrop and shadow; **PNG** saves the view at twice the resolution. If a change can't be made to work, your previous version stays on screen and **Keep fixing** picks up from where it failed.
