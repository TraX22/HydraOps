- ⌨️ **Commands.** Type `/` in the chat box and a palette lists what you can do without spending a single token: `/agents`, `/use luna`, `/status`, `/tasks`, `/delegate karen …`, `/remember`, `/recall`, `/memory`, `/telegram`, `/oneshot`, `/help` — plus `/<agent> <message>` to talk to an agent without switching tabs. English names with Spanish aliases. The same commands work in the Telegram bot. See the new *Commands* page in the docs.
- 🤝 **Agents can delegate.** The new `delegate_task` add-on lets an agent hand a task to another one (grant it in the agent's `tools.md`). And every agent now has a standing rule: if a request needs something it has no tool for, it says so — it never claims to have done it.
- ⏰ **Schedule picker for scheduled tasks.** No more typing cron syntax: pick *every N minutes*, *every day at…*, *weekdays at…* or *once a month*; existing jobs open already translated. The raw expression is still there for the curious.
- 💬 **Chat drafts survive.** What you were typing stays in its tab when you switch chats or visit another view, and a transient poll error no longer blanks the conversation.
