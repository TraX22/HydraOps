- ✉️ **Gmail: no more mail sent with an empty subject by accident.** When you ask for a new message and give no subject, the agent now asks you for one before anything reaches the approval card. If you really want it without a subject, say so and it goes out that way; the card (and the Telegram notice) then says "(no subject)" so you see it before approving. Replies and forwards are untouched: they take the subject of the original.
- 🔎 **A task's origins name what was read.** The list of outside content a task has touched used to say just `message` for an e-mail read with `gmail_read`. It now says which one (`message <id>`), and a task started by a new e-mail lists that e-mail once, not twice. Only the list changes: what marks a task and what waits for your approval is the same.
- 🛡️ **Dependencies.** `hono` 4.13.18 and `@hono/node-server` 2.1.8, after seven advisories published against earlier versions. HydraOps does not run either of them (they arrive with the MCP SDK, used only as a client), so none was reachable; the installed copies are now out of the vulnerable range.
