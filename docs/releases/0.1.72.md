- 📥 **Agents can download the models a ComfyUI workflow is missing.** The new `comfy_download_model` tool saves the file into the folder your own ComfyUI reads for that kind of model (ComfyUI itself reports it, so portable, desktop, git and extra-path installs all work). Every download waits for your approval; only https and `.safetensors` or `.gguf` files, never over an existing file. It runs in the background, and `comfy_workflows` "downloads" tells how it is going. Models behind a login (gated on Hugging Face, some on Civitai) are not downloaded yet.
- 🎛️ **Truer reports of what a workflow used.** When a value comes from another node, such as a width fed by a resolution selector or a seed from a primitive, the agent now sees it and stops reporting the number written in that field, which ComfyUI ignores.
- 🧹 **Official templates with an invisible line separator run again.** Some ComfyUI templates (MiniMax H3 among them) carry a U+2028 inside a prompt, which left the ComfyUI connection unable to read the workflow; preparing it now turns it into a normal line break.
- 🛡️ **Dependency updates.** zod moves to 4.6 across the backend, with the AI SDK and its providers on the releases built for it; undici 7.30.1, multer 2.5.0, body-parser 2.4.0 and fast-uri 4.2.3 close the remaining security advisories.
