- 📘 **The agents can read the manual.** HydraOps ships with its manual, and until now only you could read it. A new tool, `hydraops_docs`, gives it to the agents as it comes with the version you have installed: ask one how to do something in HydraOps, or why it behaves a certain way, and it looks it up (a search by words, then the page or the section it needs) instead of answering from memory or searching the web. In English or Spanish. A new agent has it from the start; to give it to an agent you already have, add it from its tools in the Agents view.
- 🧠 **"Noted" now means saved.** An agent told something about you could answer "noted" and save nothing: to use `remember` it first had to load it, one more step, and it often skipped it. `remember` is now ready from the first step of every task, and the agent is told that only the call saves, so it does not say it will remember what it did not write down.
- 👤 **Your whole profile reaches the agents.** The e-mail address in your profile was the one field they never saw. With it there, "use my personal e-mail" is enough for an agent that has several accounts to choose from.
