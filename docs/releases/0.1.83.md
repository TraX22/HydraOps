- 🩹 **Fix for 0.1.82 on Windows: the app would not start after updating.** The key store folder and the data folder are the same folder on Windows (`%APPDATA%\hydraops` and `%APPDATA%\HydraOps` only differ in case), and 0.1.82's one-time tightening of the store's permissions reached `data\`, leaving the database and the `.env` without permissions: the API died at startup and the interface stayed on the waiting page. This version never changes the folder's permissions on Windows or macOS (only the store files are made private) and **repairs an installation that 0.1.82 damaged** the first time it starts, restoring the folder's inherited permissions. If your app is stuck on the waiting page after 0.1.82: install this version from the Releases page, or reset the permissions yourself from a terminal (`icacls "%APPDATA%\HydraOps\data" /reset /T` and the same for `backups`), then start HydraOps again. Linux installations were not affected.
