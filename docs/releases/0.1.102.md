- 🧑‍💻 **Projects: an agent works on your code.** A new **Projects** section: give a project a name, a folder and an agent, and ask for changes in the project's own chat. The agent never writes in your folder. It works on its own copy of each repository, and you see what it changed as a diff.
- ✅ **You accept or discard.** Accepting saves the change in your folder as one commit on your branch, under your name; discarding drops it. Nothing is forced: if your branch changed the same lines, or your folder has unsaved work in the same files, nothing is touched and the tab says what to do. Nothing is sent to GitHub.
- 📝 **Read and edit the code in the tab.** Click a file in the tree to open it in an editor with syntax highlighting. Your own edits join the changes waiting to be accepted. While the agent works the file is read-only, and a file it changes updates by itself.
- 📌 **Instructions and notes per project.** `HydraOps.md` holds the project's instructions, and the agent follows only the text you accepted. `ProjectMemory.md` holds the notes the agent keeps about the project. A project's chat is separate from the agent's own chat.
- 🌿 **Tools → Git says what each folder is.** After saving, every allowed folder shows whether it is a repository, holds some, or is neither, so a wrong folder shows at once.
- 🏷️ **An agent's files keep their headings.** When one of an agent's files was empty, the files after it reached the model under the wrong heading (its memory labelled as its tools). Each file now goes under its own name.
- 📖 **In the manual.** A new Projects page explains how it works and what to expect.
