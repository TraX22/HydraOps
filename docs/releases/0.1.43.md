- ▶️ **The agent carries on after you approve.** Until now, approving a held call ran it and that was it: the agent had already answered "approve and I'll continue" and never saw the result, so the next request started over. Now, once you have decided on every call a task was holding (and at least one ran), the agent continues by itself in the same chat, with what each call returned and which ones you rejected, from where it stopped and with what it had already read. The chat shows it as "The agent continues after your decision", the action card shows the result, and if you approved from Telegram the follow-up reaches you there too.
