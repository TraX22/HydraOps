- 📅 **A post scheduled through the calendar is approved once.** Ask an agent to publish something on X at a later time and the calendar entry now carries the post itself. The card you approve shows the account, the text, the image or video and the date; at its time it goes out exactly like that, with no second approval waiting while you are away. There is one way to schedule now, the calendar, and it is ready for other tools to use.
- 🗓️ **A task set for later says what it is.** An entry that is work for the agent ("on Friday read the mentions") still runs as a task, and its card now says that whatever it does then that needs approval will ask you again.
- ▶️ **"Go on" works after a task that failed or that you stopped.** The request used to vanish from the conversation, so the agent carried on with whatever came before. It now stays, with a note saying it was not completed and which tools it had called.
- ⏳ **A model that takes more than five minutes on one answer is no longer cut.** The request was dropped at 300 seconds and sent again from the start, three times, which is what a local model working through a long prompt ran into. The app's own time limit per answer decides now, and says so when it is reached.
- 📖 **In the manual.** The calendar section, the Calendar page and a new troubleshooting entry for a saved post that asks for approval again.
