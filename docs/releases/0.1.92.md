- 🔄 **The Update button no longer says "no connection" when GitHub only refused the question.** GitHub allows 60 anonymous API calls an hour per public address; a desktop and a second machine on the same connection, or a few presses of "check now", used them up, GitHub answered 403, and HydraOps showed "no connection?" and kept that answer for six hours with the network fine. The latest version is now found through the releases page itself, which has no hourly limit, and the API is asked only when that fails. When a check does fail, the version line in the sidebar shows a small mark with the reason in its tooltip (no network, GitHub's limit, no published version), the Update button says which one it was, and the next check comes two minutes later instead of six hours. Nothing changes in how an update installs.
