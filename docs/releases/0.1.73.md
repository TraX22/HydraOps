- 🤗 **Hugging Face, from your agents.** New Hugging Face tools (one `huggingface` line in an agent's tools). Reading runs on its own:
  - search models, datasets and Spaces;
  - read a model's card, license and files with their download links;
  - preview a dataset's first rows;
  - follow discussions;
  - check whether your token has access to a gated model.

  Creating a repository, uploading files and posting in a discussion wait for your approval every time. Public content needs no token. Add one in **Tools → Hugging Face** for gated and private repositories, or for writing.
- 🧬 **Civitai, read-only.** Civitai tools (one `civitai` line):
  - search checkpoints, LoRAs, VAEs and more;
  - read a model's versions, trigger words, license and files, with Civitai's safety scans;
  - learn from example images with the prompt, sampler, steps, CFG and seed that made them;
  - find out which Civitai model a file you already have in ComfyUI is.

  **Adult content is blocked** unless you allow it in **Tools → Civitai**, and the agents cannot change that switch. The API key is optional; it only needs Read on Models and on Profile & Settings.
- 📥 **Gated and sign-in models download too.** `comfy_download_model` uses your Hugging Face token and Civitai key: a gated model such as FLUX.1-dev (once you accept its terms) and a Civitai model behind a sign-in now download into the right ComfyUI folder. The key goes only to that site, never to the server the file comes from. A Civitai link names its file by itself, and civitai.red links work.
- 🧩 **Workflows say which models they need.** Official ComfyUI templates carry each model's folder and download link. Preparing a workflow now lists them and says which are missing, so the agent downloads exactly the file the template asks for instead of guessing a link. An agent with `comfy_download_model` no longer tries the ComfyUI connection's own download first, which failed and could hold later steps for approval.
